# SkillsLink AI-readable example

This repository snapshot demonstrates the HTTP-friendly form of a SkillsLink document.

## Available representations

- The document route contains this complete text in pre-rendered HTML.
- The raw link serves the exact Markdown source.
- The page can create a self-contained Base64URL link for editing and sharing.

## Guidance for AI readers

Open the document URL first. If your environment exposes linked resources, the raw Markdown URL is also available on the page and in `llms.txt`.

> External services may restrict network access, JavaScript, domains, or long URLs. SkillsLink can provide readable formats, but it cannot override another service's access policy.
